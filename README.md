C++ Fundamentals

This repository documents my C++ journey as I build a strong understanding of the language and its core concepts.

## Topics

* Variables and keyboard input
* Exceptions and exception handling
* Loops, arrays, and vectors
* Using standard library algorithms
* Lambdas and the Ranges library
* Random number generation
* Working with files
* Strings and formatting
* Classes | Member variables and member functions
* Classes | Special member functions and move semantics
* Memory management with `std::unique_ptr`
* Classes | Virtual functions and inheritance
* Using `std::variant` and `std::visit`
* Templates and `std::unordered_map`

## How to Compile and Run

Using `g++`:

```bash
g++ input.cpp -o input.exe
```

Run the compiled program:

```powershell
.\input.exe
```

The same process can be used for the other `.cpp` files by replacing `input.cpp` with the relevant source file.
